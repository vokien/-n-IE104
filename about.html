Sứ Mệnh & Tầm Nhìn Dự Án

Học kỳ I / 2026

Scopus & CORE Academic Venue Recommender là nền tảng số hỗ trợ các nhà nghiên cứu, giảng viên, học viên cao học và sinh viên đại học trong quá trình định vị, tra cứu và lựa chọn nơi công bố kết quả nghiên cứu khoa học thích hợp nhất (Hội nghị quốc tế / Tạp chí chuyên ngành).

Hệ thống giải quyết bài toán mất cân xứng thông tin, giúp tác giả nắm bắt chuẩn xác thứ hạng Scopus Quartiles (Q1-Q4), phân hạng hội nghị uy tín CORE 2026 (A*, A, B, C), hạn nộp Call for Papers (CFP) theo múi giờ chuẩn quốc tế AoE (Anywhere on Earth), và tự động so khớp phạm vi bài báo qua thuật toán xử lý ngôn ngữ tự nhiên.

100% Vanilla Code

Cam kết tuyệt đối không sử dụng thư viện hoặc framework CSS/JS (không Bootstrap, Tailwind, React, jQuery). Toàn bộ mã nguồn do nhóm lập trình từ đầu.

Kiến Trúc Bánh Xe (Wheel)

Tuân thủ mô hình điều hướng Hub-and-Spoke với Trang chủ (index.html) làm trục điều phối trung tâm kết nối hai chiều đến tất cả trang vệ tinh.

Thuật Toán NLP Okapi BM25

Triển khai thuật toán so khớp độ tương đồng ngữ nghĩa BM25 thuần JavaScript phía client, tính toán điểm phù hợp trực tiếp mà không cần backend nặng nề.

Mỗi thành viên chịu trách nhiệm chuyên trách một phân hệ độc lập và phối hợp qua Git Workflow chuẩn.

Chuẩn Mực Khoa Học & Công Nghệ Áp Dụng

Scopus & CORE

Cơ Sở Dữ Liệu Tham Chiếu

  • Scopus / SCImago Journal Rank (SJR): Phân chia tạp chí thành 4 phân vị (Quartiles) Q1, Q2, Q3, Q4 dựa trên mức độ trích dẫn trung bình.
  • CORE Conference Rankings: Hệ thống xếp hạng hội nghị quốc tế uy tín do Hiệp hội Giáo dục và Nghiên cứu Điện toán Australasia (CORE) duy trì (A*, A, B, C).
  • AoE (Anywhere on Earth): Múi giờ chuẩn hóa (UTC-12) cho phép tác giả nộp bài muộn nhất khi bất kỳ nơi nào trên Trái Đất vẫn còn trong ngày hết hạn.

Tiêu Chuẩn Lập Trình Web

  • Semantic HTML5: 100% sử dụng đúng thẻ ngữ nghĩa (<header>, <nav>, <main>, <section>, <article>, <figure>, <footer>).
  • CSS Custom Properties (Variables): Quản lý tập trung toàn bộ màu sắc, kích thước, khoảng cách và chuyển đổi theme Light/Dark mượt mà.
  • Client-Side Storage: Tận dụng Web Storage API (localStorage) lưu trữ dữ liệu cục bộ bảo mật, không phụ thuộc máy chủ.
